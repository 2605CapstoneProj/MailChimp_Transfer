
## MailChimp API Integration

This tool uses the MailChimp API to:
- Authenticate with your MailChimp account
- Create and manage contact lists
- Batch upload contact data
- Handle API responses and errors

## Troubleshooting

**API Key Issues**: Ensure your MailChimp API key is correctly set in the configuration
**Data Mapping**: Verify that all required columns are present in your Google Sheet
**Rate Limits**: MailChimp has rate limits; large batches may need to be split
